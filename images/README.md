# IMD AI Challenge - Image Dataset & Sources

This directory contains the 20 self-hosted images used in the **Real vs AI Challenge**.

### Folder Organization
All images are organized with clean prefixes:
- `01_real.jpg`, `03_real.jpg`, `05_real.jpg`, ... $\rightarrow$ **Human Masterpieces (Real)**
- `02_ai.jpg`, `04_ai.jpg`, `06_ai.jpg`, ... $\rightarrow$ **AI Generated Artworks (AI)**
